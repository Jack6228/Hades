==================================
Overview
==================================

Explore real-world geochemical and magmatic workflows. Every case study contains dual guides showing how to perform the analysis in **both** the **Desktop Application** and the **Python API**.

Each case study includes step-by-step instructions to replicate the example in Hades, as well as all of the input files, both raw and as pre-configured ``.hades`` file which can be imported directly into Hades. Each case study also includes a Python Jupyter Notebook demonstrating how to perform the same analysis programmatically using the Python API.

If you want to learn more about each example in a more detailed scientific capacity, please refer to the accompanying publication (in prep.).
