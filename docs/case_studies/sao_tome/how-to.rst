Walkthrough
===================

..

----

Data Suite
------------

To model the fractional crystallisation of the lavas from São Tomé, we configure Hades to investigate an alkaline suite of rocks and load the ``sao_tome.xlsx`` data suite file. Clicking on the 'Set Samples' button, we utilise Hades' automatically computed primitive to intermediate magma compositions but force the primary, evolved and end-point compositions to be empty (set to 'None') using the drop-down menus. Click 'Apply' to save these changes and return to the main window.

----

Mineralogy
----------

In the 'Phase Compositions' tab of the configuration window, we ensure that only olivine, titanaugite, magnetite, ilmenite, plagioclase and Na-amphibole are ticked throughout the duration of magmatic evolution. We allow Hades to use its default K\ :sub:`D` values for the minerals, and we use the default mineral compositions for each stage.

After the mineral contributions are specified, click 'Apply' to save these changes and return to the main window.

----

Running the Model
-----------------

Clicking through the 'Run' button for each relevant stage in the 'Mineral Modal Abundances' section will find the optimal bulk mineral assemblage and amount of fractional crystallisation for each stage, displaying the results in the table and plots. 

Results can be further viewed through the 'TAS Diagram' and 'View Mineralogy' buttons, or cna be exported to a PDF or Excel file using the 'export' buttons.
