v0.9.1 - 30th October 2026
---------------------------

**First pre-release version of Hades!**

To install Hades, download the ``.exe`` installer from the `Hades GitHub Releases <https://github.com/Jack6228/Hades/releases/tag/v0.9.0>`_ page and consult the ``INSTALL_INSTRUCTIONS.txt`` file included in the release for installation instructions, or see the `Installation Guide <https://hades-obol.readthedocs.io/en/latest/overview/installation.html>`_ for more details.

> NOTE: Hades as a desktop application is currently only available for Windows. If you are using macOS or Linux, please use the `Python Installation Guide <https://hades-obol.readthedocs.io/en/latest/api/python_installation.html>`_ to install Hades as a Python package.
