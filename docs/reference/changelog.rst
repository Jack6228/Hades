Changelog
===================

.. All changes should follow the structure below to enable automated release notes generation.

All versioned updates to Hades are documented on this page.

v0.8.23 - 30th October 2026
---------------------------

**First pre-release version of Hades!**

To install Hades, download the ``.exe`` installer from the [Hades GitHub Releases](https://github.com/Jack6228/Hades/releases/tag/v0.8.20) page and consult the ``INSTALL_INSTRUCTIONS.txt`` file included in the release for installation instructions, or see the [Installation Guide](https://hades-obol.readthedocs.io/en/latest/overview/installation.html) for more details.

> NOTE: Hades as a desktop application is currently only available for Windows. If you are using macOS or Linux, please use the [Python Installation Guide](https://hades-obol.readthedocs.io/en/latest/api/python_installation.html) to install Hades as a Python package.
