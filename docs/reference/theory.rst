Theory
======================

Here we provide more details on some of the theoretical and mathematical aspects of Hades. This includes the underlying petrological framework, the equations used to model magmatic processes, and the differential evolution algorithm used for parameter optimisation.

You may wish to also consult the accompanying publication for Hades, which provides a more in-depth discussion of the theory and methods used in the software.
