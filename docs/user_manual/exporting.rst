Exporting Data
====================

Once modelling has been run and the results of an optimisation are desired to be saved, Hades offers two methods: saving results to an Excel spreadsheet, or saving results to a detailed PDF report. To save results to an Excel spreadsheet, click the 'Export Data' button and select a location when prompted. The resulting spreadsheet has various tabs for initial and computed magma compositions, values of mineral compositions in the bulk crystallising mineral assemblage and their abundances, and more.
 
To generate a PDF with data, results, figures, and more, the 'Export PDF' button can be clicked. It will ask what should be exported (e.g. whether to include figures in the PDF) and then prompt for a location to save the PDF. PDF generation may take a few moments, particularly if exporting many figures.
