How to Use Hades
======================

Hades is a powerful geochemical modelling tool that allows you to analyse and interpret magmatic processes. This user guide provides step-by-step instructions for installing, configuring, and using the **Hades desktop application**. Whether you're a beginner or an experienced user, this guide will help you get the most out of Hades.

Click on sections of the user manual below, or scroll to the bottom of the page to see all available topics.
