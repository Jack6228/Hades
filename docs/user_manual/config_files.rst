Configuration Files
====================

In addition to saving results from Hades, you can also export the session to a ``.hades`` file which will have the data suite and all customisable parameters (e.g. K\ :sub:`D` values, mineral usage and compositions, etc.) to a single file, which can be loaded back into Hades another time using the 'Load Config' button. To save such a file, simply click the 'Save Config' button and choose a location and filename when prompted.

These saved config files are able to be saved and loaded in both the Hades Windows application and through the ``hades-obol`` Python package, enabling the same session to be used in either environment.
