Visualisation
====================

Hades has multiple built-in visualisation methods. As well as the bivariate plots in the main window, the 'TAS Diagram' button can be used once a data suite is loaded to view the data suite and initial composition on a total alkali silica diagram. Once a LLOD is generated by Hades, it can also be viewed on this diagram.

The 'View Mineralogy' button opens a pop-up window (see image below) which shows a single plot of two major oxide elements, the data suite samples, the initial and computed magma compositions, and the mineralogy at a given phase. The drop-down boxes below the plot control which major oxides are shown in the plot, and the 'Phase transition' drop-down on the right side controls which phase is highlighted, and thus which mineral compositions are overlain. Note that the plot may have an unusual initial view due to a range of values on both axes, but the search icon in the toolbar below the plot can be used to interactively zoom in on regions of the plot. The 'View Mineralogy' pop-up also shows the optimised mineral abundances and the compositions of each mineral used in the optimisation, at each phase.

The image below shows the 'View Mineralogy' pop-up window for the primitive to basic stage results of the :doc:`/case_studies/sao_tome/index` case study, illustrating the table of mineral weights and compositions, and the customisable bivariate plot with overlain mineral compositions.
